# Etude & Code

Source code for the Etude & Code website, built with React, TypeScript, and Vite.

## Run locally

Requirements: Node.js 20.19 or newer.

    npm install
    npm run dev

Create a production build with npm run build; preview it with npm run preview.

## Author Studio

The Studio page is a browser-side editor. Drafts and published posts are saved in that browser's local storage. Use its export action to download Jekyll-ready Markdown; it does not commit posts to this repository or sync them to GitHub. The included stationery catalogue is a presentation only and has no checkout.

This repository contains the standalone app source. GitHub Pages deployment is not configured.
